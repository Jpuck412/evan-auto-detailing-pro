# Evan's Auto Detailing Pro

Premium, mobile-first automotive detailing website built with Next.js, React, and TypeScript.

## Experience
- Cinematic 3D automotive hero using layered CSS perspective and lighting
- Premium service architecture for interior, exterior, full details, paint enhancement, ceramic protection, and maintenance
- Conversion-focused quote funnel
- Process, proof, and social-proof sections
- Responsive design for phones, tablets, foldables, and desktop
- SEO metadata and Open Graph setup
- Reduced-motion accessibility support
- Vercel-ready Next.js production build

## Development
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm start
```
